## 〇、环境准备与安装

### 1. Python 依赖一键安装

```bash
pip install ase seekpath numpy scipy matplotlib spglib phonopy pyyaml
```

### 2. 外部工具依赖

| 工具 | 用途 | 需要它的脚本 |
|------|------|--------------|
| vaspkit | 生成 POTCAR、K 路径 | mol_to_vasp.py、single_atom.py、phonocal、workbd |
| phonopy | 声子计算 | mkphono、phonocal、xuping.py |
| PBS (qsub) | 集群提交 | 所有工作流、suball、tijiao |
| Linux 集群 | 运行环境 | 全部 bash 脚本、bader 二进制 |

### 3. 安装到 PATH（推荐用法）

```bash
# 1. 创建脚本存放目录并复制所有脚本
mkdir ~/Script
cp -r <本仓库各模块内的脚本> ~/Script/

# 2. 写入 PATH（把 <绝对路径> 替换为实际路径）
echo 'export PATH=<脚本目录绝对路径>:$PATH' >> ~/.bashrc
source ~/.bashrc

# 3. 赋予可执行权限
chmod u+x ~/Script/*
```

安装成功后（文件名变绿色），在服务器任意位置直接输入脚本名即可使用，例如 `jtpd`、`suball`、`clear_vasp`。

## 一、结构优化与 EOS 拟合

### 1. autovasp（v7.0）— VASP 晶胞智能自动优化器

- **位置**：`python托管自动优化/7.0/autovasp`
- **功能**：Shell 脚本，运行后生成 `vasp_infinite_wait.py` 全自动晶胞优化引擎。核心特性：
  - 双模式：`OPT`（全自动晶胞优化至应力收敛）/ `MONITOR`（仅监控并邮件通知）
  - 对称性保护：spglib 多容差扫描（0.001~0.5），自动寻找最高空间群并维持晶系
  - 自适应学习率：震荡惩罚（过零减半）、信噪过滤（局部学习率平滑融合）、动态收紧应变上限
  - 晶轴同步：`SYNC_MODE='AB'`（四方/六方）或 `'ABC'`（立方）强制等轴变形
  - 电子步不收敛自动重试（最多 N 次，自动从 CONTCAR 重启）
  - 邮件通知（QQ 邮箱 SMTP + SSL，可附带优化曲线附件）、自动绘制应力-迭代曲线
- **依赖**：python3、spglib、ase（matplotlib 可选）
- **用法**：

```bash
bash autovasp                                        # 生成 vasp_infinite_wait.py
nohup python3 -u vasp_infinite_wait.py > stdout.log 2>&1 &
tail -f auto_opt.log                                 # 查看实时日志
```

- **配置**（编辑生成的 `vasp_infinite_wait.py` 顶部配置区）：
  - `SCRIPT_MODE`：`'OPT'` / `'MONITOR'`
  - `ENABLE_SYMMETRY`：对称性保护开关（强烈建议开启）
  - `SYNC_MODE`：`'None'`/`'AB'`/`'ABC'`
  - `OPT_A/B/C`：各晶轴优化开关（2D 材料通常关闭 `OPT_C`）
  - `TARGET_TOLERANCE`：应力收敛阈值（默认 1.0 kB）
  - `INITIAL_ALPHA`：初始学习率（默认 0.0005）、`MAX_ITER`（默认 20）
  - `MAX_STRAIN_PER_STEP`：单步最大形变（默认 0.04）
  - `ENABLE_EMAIL`：邮件通知开关（需配置 SMTP，见[附录 B](#附录-b邮件通知配置)）
- **输出**：优化后 `POSCAR`、`auto_opt.log`、`opt_progress.png`、`CONTCAR`
- **注意**：v1.0~v6.0 为历史版本，仅保留供参考。

### 2. setup_eos — EOS 批量计算文件夹生成器

- **位置**：`优化拟合/setup_eos`
- **功能**：在当前目录创建 0.95~1.05（步长 0.01）共 11 个缩放系数文件夹，每个含 `INCAR/KPOINTS/POTCAR/POSCAR/wk.pbs`，并自动改写 POSCAR 第 2 行的缩放系数。
- **依赖**：无（纯 bash）
- **用法**：

```bash
# 当前目录需有 INCAR KPOINTS POTCAR POSCAR wk.pbs
bash setup_eos
```

- **输出**：`0.95/ 0.96/ ... 1.05/` 共 11 个文件夹
- **注意**：原始 POSCAR 第 2 行建议为 1.0，脚本会覆盖该值。

### 3. nihe.py — Birch-Murnaghan EOS 拟合

- **位置**：`优化拟合/nihe.py`
- **功能**：遍历 0.95~1.05 文件夹，从 OUTCAR 提取体积和晶格常数、从 OSZICAR 提取 E0，用三阶 Birch-Murnaghan 方程非线性最小二乘拟合，输出平衡体积 V0、最优晶格常数 a/b/c、体模量 B0（GPa），并绘制 300 DPI 拟合曲线。
- **依赖**：numpy、scipy、matplotlib
- **用法**：将脚本放在 0.95~1.05 文件夹的**上级目录**，`python nihe.py`
- **输出**：终端打印 V0/E0/B0/a/b/c + `EOS_Fit.png`
- **注意**：基准文件夹名支持 `1.00` 或 `1.0`。

## 二、K 点与能带/态密度/MD 绘图

### 4. KPATHS.py — 高对称 K 点路径自动寻找

- **位置**：`K点寻找/KPATHS.py`
- **功能**：基于 SeeK-path 识别空间群，自动生成标准高对称 K 点路径（Line-mode KPOINTS，20 个插值点/段）和标准化原胞 `POSCAR_std`。支持 POSCAR/cif/xsf 等 ASE 可读格式。
- **依赖**：ase、seekpath、numpy
- **用法**：将 POSCAR 放在当前目录，`python KPATHS.py`
- **输出**：`KPOINTS_seekpath`、`POSCAR_std`
- **注意**：**必须**使用生成的 `POSCAR_std` 做能带计算，否则 K 点路径与结构不匹配。

### 5. bandcal — 能带图自动绘制

- **位置**：`band+dos绘制/bandcal`
- **功能**：读取 vaspkit 生成的 `BAND.dat` 和 `KLABELS`，自动绘制能带结构图。自动检测 OUTCAR 中 ISPIN：非磁性蓝色；自旋极化蓝色（上）/绿色（下）。Gamma 自动替换为希腊字母，Y 轴 -10~+10 eV，300 DPI。
- **依赖**：python3、matplotlib、numpy
- **用法**：当前目录有 `BAND.dat` 和 `KLABELS`（vaspkit 21 生成）后 `bash bandcal`
- **输出**：`band_structure.png`

### 6. doscal — PDOS 图自动绘制

- **位置**：`band+dos绘制/doscal`
- **功能**：自动检测 `PDOS_ELEMENTS.dat`（非磁性）或 `PDOS_ELEMENTS_UP/DW.dat`（自旋极化）。Spin Down 翻转为负值，样条插值平滑，Nature 8 色调色板，填充面积图，自动 Y 轴范围。
- **依赖**：python3、matplotlib、numpy、scipy
- **用法**：当前目录有 vaspkit 生成的 PDOS 文件后 `bash doscal`
- **输出**：`PDOS_final_v4.png`

### 7. mdcal — MD 能量轨迹绘图

- **位置**：`md绘制/mdcal`
- **功能**：从 OSZICAR 提取 MD 步数和总能量，以平均能量为基准对称设置 Y 轴，绘制 Nature 风格能量轨迹图（深钴蓝曲线 + 灰色均值参考虚线），X 轴自动转换为 ×10³ 步。
- **依赖**：python3、matplotlib、numpy
- **用法**：当前目录有 OSZICAR 后 `bash mdcal`
- **输出**：`MD_Energy_Centered.png`、`md.dat`（check_md v3.0 会用到此文件）

## 三、NEB 过渡态

### 8. idpp.py — IDPP 过渡态插点

- **位置**：`IDPP过渡态插点/idpp.py`
- **功能**：利用 ASE 的 IDPP 算法在初末态间插值生成 NEB 中间结构。末态晶胞自动对齐初态（`set_cell + scale_atoms=True`）避免 "Variable cell" 报错，支持周期性边界。生成 `00~XX` 格式计算文件夹和 `.traj` 可视化轨迹。
- **依赖**：ase、numpy
- **用法**：

```bash
# 初态命名 initial.poscar，末态命名 final.poscar
# 编辑脚本中 n_images 设置中间插点数（不含头尾）
python idpp.py
```

- **输出**：`00/ 01/ ...` 文件夹（各含 POSCAR）+ `idpp_path_fixed.traj`
- **注意**：初末态原子数必须一致；需自行复制 POTCAR/KPOINTS/INCAR 到各文件夹，INCAR 中 `IMAGES` 应与 n_images 一致。

### 9. huitu.py — NEB 能垒曲线绘制

- **位置**：`IDPP过渡态插点/huitu.py`
- **功能**：从 00-XX 文件夹的 OUTCAR（或 vasprun.xml 兜底）提取势能和坐标，计算反应坐标（PBC 最小镜像），PchipInterpolator 平滑插值（300 点），绘制 NEB 能垒曲线，自动标注活化能 Ea 和初/末态辅助水平线。
- **依赖**：ase、scipy、matplotlib、numpy
- **用法**：当前目录有 `00, 01, 02...` NEB 计算文件夹（含 OUTCAR）后 `python huitu.py`
- **输出**：`neb_ase_final_line.png` + `.pdf`（矢量图，适合论文插图）

## 四、声子计算

### 10. mkphono — Phonopy 超胞一键生成与分发

- **位置**：`声子/mkphono`
- **功能**：交互式输入数字（如 161 → 1×6×1），创建 `phonopy<num>/` 文件夹，将 CONTCAR 改为 POSCAR 并把 INCAR 改为静态计算（IBRION=-1, NSW=0），运行 `phonopy -d` 生成位移结构，自动检测 `POSCAR-*` 并分发到 `01/ 02/ ...` 子文件夹。
- **依赖**：phonopy
- **用法**：

```bash
# 当前目录需有 CONTCAR INCAR KPOINTS POTCAR wk.pbs
bash mkphono
# 按提示输入 3 位数字，如 221 表示 2x2x1 超胞
```

- **输出**：`phonopy<num>/` 文件夹（含 SPOSCAR 和 01/ 02/ ... 子文件夹）

### 11. phonopy.py — 手动超胞位移生成器（不依赖 phonopy 命令）

- **位置**：`声子/手动超胞/phonopy.py`
- **功能**：读取原胞 POSCAR，用 spglib 找不可约原子位移（±0.01 Å 正反双向），生成所有位移 POSCAR 和完美兼容 phonopy 的 `phonopy_disp.yaml`。支持对角/非对角扩胞矩阵。
- **依赖**：numpy、spglib、yaml
- **用法**：原胞 POSCAR 放入当前目录，`python phonopy.py`，按提示输入超胞倍数（如 `2 2 2`，回车默认 2×2×2）
- **输出**：`SPOSCAR`、`POSCAR-001/002/...`、`phonopy_disp.yaml`

### 12. band_conf — band.conf 交互式生成器

- **位置**：`声子/自动后处理1.0/band_conf`
- **功能**：交互式输入 DIM（扩胞尺寸）生成 phonopy 能带计算的 `band.conf`。BAND 路径为默认值，需手动改为实际体系的高对称路径。
- **依赖**：无（纯 bash）
- **用法**：`bash band_conf`，按提示输入扩胞尺寸（如 `2 2 2`）
- **注意**：日常使用推荐 phonocal（v3.0），已内置自动推算 DIM 和高对称路径。

### 13. phonocal（v3.0）— Phonopy 全自动计算与后处理

- **位置**：`声子/自动后处理3.0/phonocal`
- **功能**：一键完成声子谱全流程，三阶段：
  1. 调用 vaspkit 302 获取 KPATH.in，自动推算 DIM（优先读 phonopy_disp.yaml，兜底对比原胞/超胞晶格），生成 band.conf
  2. 批量提取子目录 vasprun.xml 合成 FORCE_SETS，计算力常数，绘制声子色散图
  3. 虚频智能诊断：< -0.15 THz（FFT 网格噪声）/ -0.15~-0.6（亚稳态）/ < -0.6（本质不稳定）三档分析，读取 INCAR/KPOINTS 快照给出针对性建议
- **依赖**：vaspkit、phonopy、python3、matplotlib、numpy
- **用法**：当前目录有 POSCAR（原胞）和已完成计算的子文件夹 vasprun.xml 后 `bash phonocal`
- **输出**：`band.conf`、`FORCE_SETS`、`phonon_dispersion.png`、虚频分析报告（终端）

### 14. xuping.py — 虚频消除器（增强 ASR + 对称性修正）

- **位置**：`消除虚频/xuping.py`
- **功能**：自动对比 POSCAR/SPOSCAR 计算超胞矩阵，用 phonopy 读取 FORCE_SETS 计算力常数后双重修正：(1) 增强 ASR（行残差平均分配 + 对角项约束）；(2) 晶体对称性修正 `symmetrize_force_constants()`。输出修正后的 FORCE_CONSTANTS，消除 Gamma 点附近虚频。
- **依赖**：phonopy、numpy
- **用法**：当前目录有 `POSCAR SPOSCAR FORCE_SETS` 后 `python xuping.py`
- **输出**：`FORCE_CONSTANTS` + 终端打印建议绘图命令
- **注意**：修正后绘图必须加 `--readfc`：

```bash
phonopy -p -c POSCAR --dim='2 2 2' --readfc band.conf
```

## 五、AFM 磁构型与磁基态

### 15. afm.py — AFM 磁构型自动生成器

- **位置**：`afm寻找和建立/afm.py`
- **功能**：根据 POSCAR 自动生成多种反铁磁构型：索引交替（AFM_idx）、沿 X/Y/Z 分层的层间 AFM、G-type 3D 棋盘格 AFM。各构型自动生成正确 MAGMOM 的 INCAR（ICHARG=2, ISTART=0），智能文件夹命名，自动去重。
- **依赖**：ase、numpy
- **用法**：

```bash
# 当前目录需有 POSCAR INCAR POTCAR KPOINTS job.sh
# 编辑脚本中 MAG_ELEMENT（磁性元素）和 MAG_VALUE（磁矩大小）
python afm.py
```

- **输出**：`FM/ afm_idx_*/ AFM_Layer_X_*/ AFM_Layer_Y_*/ AFM_Layer_Z_*/ AFM_G_Type_*/`
- **注意**：优先检查 AFM_Layer_X/Y/Z 系列（物理意义最明确）。

### 16. jtpd — 磁基态快速诊断

- **位置**：`基态判断/jtpd`
- **功能**：遍历所有子文件夹 OUTCAR，自动过滤未完成/未收敛任务（NELM 耗尽 + General timing 检查），提取每原子能量和磁矩，智能判定 NM/AFM/FM/FiM，找出能量最低基态并计算与次低态能差。ΔE < 2 meV/atom（热能简并）时发出警告。
- **依赖**：无（纯 bash + awk）
- **用法**：在包含多个磁构型计算文件夹的目录下 `bash jtpd`
- **输出**：终端基态判定报告（绿色=可靠，红色=简并警告）

## 六、吸附模型搭建

### 17. slab.py（v8.0）— 全自动吸附模型搭建

- **位置**：`吸附模型搭建/slab/8.0/slab.py`
- **功能**：从 slab POSCAR 出发，自动识别顶位/桥位/空位吸附位点。五大核心引擎：
  1. 化学直觉引擎：基于周期表趋势（3d/4d/5d/主族）+ 电负性修正计算理想键长
  2. 动态桥长引擎：桥位跨度上限 = (d_M1-A + d_M2-A) × 容差系数，硬上限 5.0 Å
  3. Delaunay 三角剖分找桥位 + Voronoi 图找空位
  4. 跨类型空间竞争合并（Top > Hollow > Bridge）
  5. 空间环境指纹去重（PBC 最小镜像）
  支持 H/O/OH/OOH 吸附物（OH/OOH 含倾角和随机旋转）。**v8.0 新增：为每个吸附构型自动生成完整 VASP 计算文件夹**（内置 INCAR/KPOINTS/wk.pbs/vasp_infinite_wait.py 监控模板，含邮件通知）。
- **依赖**：ase、numpy（推荐 scipy）
- **用法**：

```bash
# slab POSCAR 放入当前目录，编辑脚本配置区：
#   INPUT_FILE / SELECT_MODE("H"/"O"/"OH"/"OOH") / SEARCH_DIRECTION("top"/"bottom")
#   RADIUS_LIMIT / SURFACE_THICKNESS
python slab.py
```

- **输出**：`adsorption_<吸附物>_<方向>/` 下 `top/ bridge/ hollow/` 各含 .cif **及整套 VASP 计算文件**，终端输出汇总表（位点类型/组成/高度/结合原子）
- **注意**：内置 INCAR/PBS 模板（ENCUT=450、IVDW=11、qsub 等）请按自己的体系和服务器修改；1.0~7.0 为历史版本。

### 18. slabcover.py — H 覆盖度演化器（一次性生成全部覆盖度）

- **位置**：`吸附模型搭建/coverage_H/一次/slabcover.py`
- **功能**：在 slab 不同吸附位点上自动逐步增加 H 覆盖度，生成从低到高覆盖系列构型。四大引擎：化学直觉键长、动态高度修正（有效配位数 + 表面法向弛豫）、极致几何位点测绘（Delaunay+Voronoi+空间排他）、势场全局演化（1/r³ 偶极排斥 + 局域密度惩罚 + 中心引力，贪婪搜索）。
- **依赖**：ase、numpy（推荐 scipy）
- **用法**：

```bash
# slab POSCAR 放入当前目录，编辑配置：
#   ADSORBATE="H" / MAX_ATOMS(默认5) / SITES=["top","bri","hol"]
#   ADSORB_MODE="symmetric"(推荐,双面交替抵消偶极)/"top"/"bottom"
#   MIN_DIST(默认2.0 Å 安全红线) / REPULSION_POWER(默认3)
python slabcover.py
```

- **输出**：`Coverage_H_<模式>_Ultimate/{top_*, bridge_*, hollow_*}/` 各含 `cov_XXH_XT_XB_opt.cif`（文件名含顶/底面吸附原子计数）

### 19. coverage.py — 增量加 H 候选构型生成器

- **位置**：`吸附模型搭建/coverage_H/多次/coverage.py`
- **功能**：与 slabcover.py 的一次性全演化不同，本脚本用于**逐轮递增**覆盖度：读取干净表面或**已含 H 的优化后结构**（INPUT_FILE 指向 CONTCAR 即可接力），每轮新增 N_ADD 个 H，按能量评分排序并做构型多样性过滤，输出前 TOP_K 个候选构型供提交计算，适合"算一轮、挑最优、再加一轮"的迭代流程。
- **依赖**：ase、numpy（推荐 scipy）
- **用法**：

```bash

#   INPUT_FILE="POSCAR"（或上一轮优化的 CONTCAR）
#   ADSORBATE="H" / N_ADD=1（本次新增 H 数）/ TOP_K=5
#   SITES=["top"]（允许位点池）/ ADSORB_MODE="top"/"bottom"/"both"

python coverage.py
```

- **输出**：`Candidates_H_Add<N_ADD>_<模式>/` 文件夹（前 K 个候选构型）

### 20. check_ads — 吸附后底物形变评估

- **依赖**：python3、ase
- **用法**：

```bash
# 编辑脚本顶部 ADSORBATES="H"（空格分隔多个吸附物元素）
# 当前目录需有 POSCAR 和 CONTCAR
bash check_ads
```

- **输出**：终端底物形变评估报告（含最大位移原子编号，与 VESTA 序号对齐）

## 七、结合能计算

> 标准流程：`mol_to_vasp.py`（分子）+ `single_atom.py`（单原子参考）→ 提交计算 → `binding_energy.py`（汇总）。BOX_SIZE 等参数必须一致。

### 21. mol_to_vasp.py — .mol 分子文件转 VASP 输入

- **位置**：`结合能/mol_to_vasp.py`
- **功能**：批量将 .mol 分子文件转换为 VASP 计算输入：POSCAR（分子居中于真空立方盒子）、INCAR（稳健型孤立分子弛豫参数，含 AMIX/BMIX 防电荷震荡）、KPOINTS（Gamma 点）、POTCAR（调用 vaspkit 103）、PBS 提交脚本（双服务器 VASP 路径自适应）。
- **依赖**：vaspkit
- **用法**：将 .mol 文件放入当前目录，`python mol_to_vasp.py`
- **输出**：每个分子一个文件夹（POSCAR/INCAR/KPOINTS/wk.pbs/POTCAR）
- **注意**：`BOX_SIZE`（默认 20 Å）需与单原子计算保持一致。

### 22. single_atom.py — 单原子能量计算任务生成器

- **位置**：`结合能/single_atom.py`
- **功能**：交互式输入元素符号，自动生成真空盒子单原子 VASP 计算任务（ISPIN=2、IBRION=-1 静态、PREC=Accurate、ISYM=0、LREAL=.FALSE.）。
- **依赖**：vaspkit
- **用法**：`python single_atom.py`，输入元素符号（空格分隔），如 `C H O Fe`
- **输出**：`atom_<元素>/` 文件夹（含全套输入文件）
- **注意**：`BOX_SIZE`（默认 15 Å）、`ENCUT`（默认 450 eV）必须与物质计算一致。

### 23. binding_energy.py — 结合能自动计算器

- **位置**：`结合能/binding_energy.py`
- **功能**：扫描 `atom_<元素>` 文件夹获取单原子参考能量（energy(sigma->0) 优先），扫描其他物质文件夹获取总能量，从 POSCAR/CONTCAR 读化学式（兼容 VASP 4/5），计算 `E_binding = E_total - Σ(n_i × E_atom_i)`。
- **依赖**：无（纯标准库）
- **用法**：构造目录 `atom_C/ atom_H/ ... + 物质文件夹（如 CO2/）`，`python binding_energy.py`
- **输出**：`binding_energy_results.dat`
- **注意**：单原子文件夹必须以 `atom_` 为前缀。

### 24. yuansutongji.py — 元素统计器

- **位置**：`结合能/yuansutongji.py`
- **功能**：递归遍历所有子文件夹，统计所有 POSCAR 的元素组成（兼容 VASP 4/5 格式），输出格式化表格和全局汇总。
- **依赖**：无（纯标准库）
- **用法**：`python yuansutongji.py`

### 47. workflow — 单体 VASP 自动化高通量工作流

- **位置**：`工作流/单体优化工作流/workflow`
- **功能**：生成 `workflow_master.py`，自动完成六步：
  1. 单胞无磁（NM）计算（K 网格 9×9×1）
  2. 单胞铁磁（FM）计算（ISPIN=2，继承 NM 的 CONTCAR）
  3. 调用 jtpd 诊断磁基态，选定 NM/FM 最低能态作为扩胞起点
  4. 扩胞（2×2×1，ASE make_supercell）无磁计算
  5. 扩胞铁磁计算（7×7×1）
  6. 高精度收敛验证（13×13×1，PREC=A，EDIFF=1e-8，EDIFFG=-0.001）
  全程自动提交、守护、邮件汇总，每步完成后自动清理中间文件。
- **依赖**：python3、ase、numpy；autovasp、jtpd、pos2cif.pl、clear_vasp、ISPIN（需在 PATH 中）
- **用法**：

```bash
# 当前目录有 POSCAR INCAR POTCAR KPOINTS wk.pbs
bash workflow
nohup python3 -u workflow_master.py > workflow.log 2>&1 &
tail -f workflow.log
```

- **配置**（生成文件顶部 CONFIG）：`KPOINTS_SINGLE/KPOINTS_SPC221/KPOINTS_ACCURATE`、`ENABLE_EMAIL`、SMTP 参数
- **输出**：`single/{nm,fm}/ spc221/{nm,fm}/ single/<基态>/Accurate/` + `workflow_report.txt` + 邮件

- **功能**：一键完成从优化后结构到 ZPE 振动频率计算的部署：创建 `zpe/` 文件夹，根据**路径名**自动判断吸附物类型（OOH/OH/H，相应解冻末部 3/2/1 个吸附原子，衬底全冻结 F F F），写入频率计算 INCAR（IBRION=5, NFREE=2, POTIM=0.02, NSW=1, ISYM=0）并自动继承原 INCAR 的 ISPIN，生成 MONITOR 模式监控脚本（邮件通知），后台自动提交。
- **依赖**：python3、qsub（PBS）
- **用法**：

```bash
# 当前目录有优化后的 CONTCAR/INCAR/POTCAR/KPOINTS/wk.pbs
# 注意当前目录路径名需包含 OOH/OH/H 关键词
bash workzpe
tail -f zpe/auto_opt.log
```

- **输出**：`zpe/` 文件夹 + 后台监控进程

### 50. workbd — 能带+态密度全自动工作流

- **位置**：`工作流/band+dos计算工作流/workbd`
- **功能**：生成 `vasp_workflow.py` 并**自动 nohup 后台启动**，四阶段全自动：
  1. **SCF 静态自洽**（`scf/` 文件夹，提交并等待完成）
  2. **BAND+DOS 联合计算**：从 OUTCAR 提取 NBANDS 并 +60，调用 vaspkit 302 生成 KPATH.in 作为 KPOINTS，改 INCAR 为 ICHARG=11 非自洽（`band+dos/` 文件夹）
  3. **数据提取与自动绘图**：vaspkit 静默后处理，自动绘制 band_structure.png 和 PDOS 图
  4. **成果打包归档**至 `png_dat/` 文件夹
- **依赖**：python3、vaspkit、qsub（PBS）、matplotlib、numpy
- **用法**：

```bash
# 当前目录有优化后的结构 (CONTCAR 或 POSCAR) + INCAR POTCAR KPOINTS wk.pbs
bash workbd        # 自动后台运行
tail -f workflow.log
```

- **输出**：`scf/ band+dos/ png_dat/`（能带图 + PDOS 图 + 数据文件）+ `workflow.log`

SMTP_SERVER     = "smtp.qq.com"            # QQ 邮箱 SMTP
